# Malachi SEO audit — 2026-08-02

## Scope

Read-only review of the live static site plus local source review. The public
canonical host is `https://malachi-static.onrender.com/`.

## Critical findings fixed in source

- The live `robots.txt` and `sitemap.xml` returned HTTP 404.
- The homepage had no meta description or canonical URL.
- The homepage had no Open Graph or Twitter sharing metadata.
- The homepage had no structured data.
- The static build copied HTML/CSS/JS only, so SEO text/XML files and brand
  assets were not guaranteed to reach a clean build output.
- The homepage title was brand-only and did not describe the search intent.

## Implemented

- Added a descriptive Hebrew title and meta description targeting the core
  intent: a daily WhatsApp connection check for an older adult.
- Added canonical, robots, Open Graph and Twitter metadata.
- Added JSON-LD for the organization, website and service.
- Added `robots.txt` and a focused XML sitemap containing only useful public
  information pages.
- Updated the static build to copy XML, text files and brand assets.

## Next priorities after deployment

1. Verify the live homepage, `robots.txt`, `sitemap.xml` and social preview.
2. Submit the sitemap in Google Search Console.
3. Add unique descriptions and canonicals to FAQ, onboarding and legal pages.
4. Add `noindex` to login, dashboard, admin, manager and other utility pages.
5. Measure mobile Core Web Vitals and optimize the large mascot PNG if needed.
6. Build helpful Hebrew content around family connection routines and older
   adults living alone; avoid medical or emergency-service claims.

## Guardrail

No ranking guarantee is implied. Malachi is a family connection aid, not a
medical monitoring or emergency service, and SEO copy must keep that boundary.
