# מלאכי - תבניות WhatsApp להגשה ל-Meta

חשוב: להגיש כ-Utility Templates. לא להכניס ניסוח שיווקי, מבצע, מכירה או הבטחות הצלת חיים.
שפת תבנית: Hebrew / he

## 1. optin_confirm_he
קטגוריה מבוקשת: Utility
מטרה: אישור הצטרפות האדם המבוגר לשירות.

Body:
שלום {{1}}, כאן מלאכי.
{{2}} ביקש/ה לצרף אותך לבדיקת בוקר יומית ב-WhatsApp.
בכל יום בשעה {{3}} נשלח הודעה קצרה כדי לוודא שהכול בסדר.
להמשך השירות יש לאשר קבלת הודעות.

Buttons:
- מאשר/ת (button id: approve_optin)
- לא מעוניין/ת (button id: decline_optin)

Variables example:
{{1}} = רחל
{{2}} = שלמה
{{3}} = 09:00

## 2. daily_check_he
קטגוריה מבוקשת: Utility
מטרה: בדיקת קשר יומית.

Body:
בוקר טוב {{1}}, כאן מלאכי.
רק לוודא שהכול בסדר הבוקר.

Buttons:
- הכול בסדר (button id: daily_ok)
- מצוקה (button id: daily_distress)

Variables example:
{{1}} = רחל

## 3. distress_alert_he
קטגוריה מבוקשת: Utility
מטרה: עדכון איש קשר במקרה שהאדם לחץ מצוקה.

Body:
התראת מלאכי: {{1}} לחץ/ה על מצוקה בשעה {{2}}.
מומלץ ליצור קשר ולבדוק שהכול בסדר.

Variables example:
{{1}} = רחל
{{2}} = 09:14

## 4. no_response_alert_he
קטגוריה מבוקשת: Utility
מטרה: עדכון איש קשר כאשר לא התקבלה תגובה בפרק הזמן שהוגדר.

Body:
התראת מלאכי: {{1}} לא ענה/ענתה לבדיקת הבוקר עד {{2}}.
מומלץ ליצור קשר ולוודא שהכול בסדר.

Variables example:
{{1}} = רחל
{{2}} = 10:00

## 5. service_paused_he
קטגוריה מבוקשת: Utility
מטרה: עדכון שהשירות הופסק.

Body:
שירות מלאכי עבור {{1}} הופסק.
לא יישלחו הודעות בדיקה יומיות נוספות עד להפעלה מחדש.

Variables example:
{{1}} = רחל
