# מלאכי V80 - Release Notes

## שינוי
- הוחזרו קישורים גלויים לעמודים המשפטיים המלאים מדף הנחיתה: מדיניות פרטיות, תנאי שימוש ומחיקת מידע.
- עודכן checkbox ההסכמה בטופס כך שיפנה במפורש לתנאי השימוש ולמדיניות הפרטיות.
- תוקן הדשבורד המשפחתי כך שלוג ההודעות נטען מ־`/api/outbound-messages` במקום להישאר על “טוען לוג הודעות...”.
- נוסף `healthCheckPath: /api/health` ל־Render כדי לשפר בדיקת בריאות ולצמצם סיכון לפריסה שמשרתת תקלה.

## בדיקות
- `npm test`
- `node --check` לקבצי JS מרכזיים
- בדיקת HTTP מקומית לכל הדפים המרכזיים
- בדיקת קישורים/עוגנים מקומית
- בדיקת API ללוג הודעות בדשבורד
