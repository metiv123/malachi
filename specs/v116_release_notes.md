# מלאכי V116 - סידור רגוע יותר לדשבורד המשפחתי

## מה השתנה

- שינוי רק באזור הדשבורד המשפחתי.
- אזור החשבון וקישור הניהול עבר למטה תחת “ניהול מתקדם”.
- אזור הוספת מבוגר הפך לכרטיס שקט יותר; אם אין מבוגר הטופס פתוח, ואם יש מבוגר הטופס סגור תחת פעולה ברורה.
- בכרטיס המבוגר מוצגים רק עד 3 בני משפחה כדי לא להציף את המסך; כל הרשימה וההוספה נמצאות תחת “ניהול בני משפחה והוספה”.
- הוספת בן משפחה עדיין קיימת, אבל פחות מציפה את הדף הראשי.
- נוספו סגנונות CSS רגועים יותר לאזור המשפחתי.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
