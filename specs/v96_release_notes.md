# מלאכי V96 - צור משתמש, כניסת משתמש ותשתית אימות מייל

## שינויי מוצר
- דף הבית כבר לא מכיל את טופס יצירת המשפחה המלא.
- נוסף דף נפרד: `/create-user.html` — צור משתמש.
- דף נפרד: `/login.html` — כניסת משתמש.
- אחרי יצירת משתמש נכנסים לאזור אישי, ושם מוסיפים את פרטי ההורה/האדם המבוגר, איש קשר ושעת בדיקה.
- באזור האישי, אם עדיין לא הוגדר הורה, מופיע טופס “הוספת פרטי משפחה”.
- קישור הניהול הפרטי נשאר כגיבוי.

## מיילים ושיווק
- נוסף checkbox נפרד להסכמה לקבלת עדכונים/תוכן/הצעות במייל (`marketingEmailConsent`).
- ההסכמה השיווקית נשמרת בנפרד מהסכמה לתנאי השימוש.

## פרטיות ותנאים
- עודכנו מדיניות הפרטיות ותנאי השימוש כך שיכסו:
  - מייל ופרטי חשבון
  - אזור אישי וסיסמה
  - הודעות שירות במייל
  - הסכמה נפרדת לשיווק במייל
  - ספקי תשתית כמו Firebase/Google, Render, Meta/WhatsApp וספקי מייל עתידיים

## תשתית Firebase Auth
- נוספה תשתית אופציונלית ל־Firebase Auth (`FIREBASE_AUTH_ENABLED=true`).
- כאשר Firebase Auth יופעל בפרויקט, יצירת משתמש תוכל ליצור גם משתמש Firebase ולייצר קישור אימות מייל.
- כרגע Firebase Authentication / Identity Toolkit עדיין לא מופעל בפרויקט, וה־service account אינו מורשה להפעיל אותו לבד.
- נדרש להפעיל ידנית ב־Firebase Console:
  - Authentication
  - Sign-in method: Email/Password
