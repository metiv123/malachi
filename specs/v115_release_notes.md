# מלאכי V115 - הבהרת בן משפחה ראשון בטופס הוספת מבוגר

## מה תוקן

- בטופס הוספת מבוגר נוסף נוספו כותרות משנה ברורות:
  - פרטי האדם לבדיקה
  - בן משפחה ראשון להתראות
  - הגדרות אי־מענה
- נוסף הסבר שהבן משפחה הראשון נשמר יחד עם המבוגר, ואחרי השמירה אפשר להוסיף בני משפחה נוספים.
- כפתור השמירה שונה ל־“שמירת המבוגר ובן המשפחה הראשון” כדי להבהיר שזו גם פעולת הוספת בן משפחה.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
