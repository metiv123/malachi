# מלאכי V87 - Flow בדיקה אמיתי ואישור בן משפחה

## מה נוסף
- בן/בת משפחה כאיש קשר מקבל/ת עכשיו סטטוס אישור WhatsApp משלו/ה (`pending` / `approved` / `declined`).
- בהרשמה חדשה נשלחות שתי בקשות אישור:
  - להורה/מבוגר
  - לבן/בת המשפחה שמקבל/ת התראות
- נוספה תבנית Meta חדשה נדרשת: `contact_optin_he`.
- דשבורד המשפחה מציג לכל איש קשר את מצב האישור שלו.
- נוספו כפתורי “שלח אישור שוב”:
  - להורה
  - לכל איש קשר להתראות
- התראות no-response / ד״ש / מצוקה ישנה נשלחות רק לאנשי קשר שאישרו קבלת התראות.
- עדכון טלפונים דרך הדשבורד מנרמל מספרים ישראליים (`052...` → `+97252...`).
- בהרשמה, אם שליחת WhatsApp נכשלה בגלל Meta/template, המשפחה עדיין נוצרת והדשבורד מוצג עם אזהרה במקום לשבור את הטופס.

## למה
המשתמש רוצה לבדוק flow אמיתי מהאתר: הכנסת פרטים, שליחת הודעות, קליטת אישורים, עדכון זמנים וניהול. בנוסף הובהר שגם בן המשפחה צריך לאשר קבלת התראות, ולא רק ההורה.

## מגבלות ידועות
- `contact_optin_he` צריכה להיות מאושרת ב-Meta לפני ששליחת אישור לבן משפחה תעבוד ב-live.
- webhook של Meta ללחיצות כפתור עדיין דורש בדיקה/תיקון subscription בצד Meta; הקוד עצמו מעבד payload תקין בהצלחה.
