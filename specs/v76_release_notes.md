# מלאכי V76 - Release Notes

## תיקון פוטר וקישורי מידע
- פוטר דף הבית הוחלף מרשימת קישורי טקסט צפופה לרכיב קישורים ברור ונוח ללחיצה במובייל.
- הוסר הקישור “סטטוס” מהפוטר הציבורי כי הוא לא ברור למשתמש רגיל.
- קישורי הפוטר החדשים:
  - איך מתחילים
  - שאלות ותשובות
  - פרטיות
  - תנאי שימוש
  - מחיקת מידע
- נוסף טקסט הבהרה קצר בפוטר: מלאכי הוא כלי עזר משפחתי ואינו מוקד חירום או שירות רפואי.

## שיפור כפתור נגישות
- כפתור הנגישות עודכן לכפתור צף ברור יותר עם סמל נגישות.
- במובייל הכפתור מצטמצם לסמל צף כדי לא להסתיר תוכן.
- נוספו label ו-ARIA ברורים לפתיחת תפריט הנגישות.

## בדיקות
- `npm test` עבר בהצלחה.
- `npm run test:consistency` עבר בהצלחה.
