# מלאכי V77 - Release Notes

## תיקון קישורי פוטר ונגישות צפה
- קישורי הפוטר בדף הבית הוחלפו מעמודים נפרדים לעוגנים בתוך אותו דף, כדי לצמצם תקלות ניווט/502 בדפדפני מובייל או בזמן cold start.
- נוסף אזור מידע פנימי בדף הבית עם:
  - איך מתחילים
  - שאלות ותשובות
  - פרטיות
  - תנאי שימוש
  - מחיקת מידע
- עדיין נשמרים קישורים לעמודים המלאים מתוך כרטיסי המידע, אבל הפוטר עצמו כבר לא תלוי בניווט לדף חדש.
- כפתור הנגישות חוזק ל־floating אמיתי עם `position: fixed !important`, z-index גבוה, סמל בלבד, והתאמה למובייל.

## בדיקות
- `npm test` עבר בהצלחה.
- `npm run test:consistency` עבר בהצלחה.
