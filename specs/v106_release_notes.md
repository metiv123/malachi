# מלאכי V106 - הקשחה משפטית ואבטחתית

## מטרת הגרסה
לתקן את כל הסיכונים שניתן לתקן מתוך הקוד בעקבות ביקורת משפטית/תפעולית מחמירה לפני פיילוט ציבורי.

## אבטחה
- נוסף `MALACHI_ADMIN_TOKEN` להגנת דפי אדמין ו־API ניהוליים.
- דפי אדמין נעולים:
  - `/admin.html`
  - `/admin-feedback.html`
  - `/admin-marketing.html`
- נתיבי GET ניהוליים נעולים, כולל Dashboard, Waitlist, Feedback listing, Audit, Errors, Exports, Readiness ו־Meta admin.
- נתיבי POST פנימיים/בדיקות נעולים, כולל jobs, mock webhook/respond, demo family ו־Meta template submit.
- `POST /api/feedback` נשאר ציבורי כדי שמשתמשים יוכלו לשלוח פידבק.
- `POST /api/marketing/consent` נשאר ציבורי לצורך הסרה מדיוור לפי מייל.
- `POST /api/elders/:id/send-check` דורש כעת family token תקף ותואם לאותו elder.
- נתיבי `/api/*` שלא קיימים מחזירים 404 במקום לנסות להיטען כקובץ סטטי.
- static files מקבלים Content-Type תקין גם לתמונות PNG/ JPG / SVG, ותמיכה ב־HEAD.

## דשבורד
- הוסרה חשיפת כפתורי דמו ציבוריים מהאזור האישי:
  - דמה אני בסדר
  - דמה אין תגובה
  - דמה הסרה בוואטסאפ
- שליחת בדיקה ידנית מהדשבורד שולחת כעת גם token לאימות.
- בהוספת הורה נוסף checkbox מחייב: האדם יודע/יקבל הסבר והשירות יופעל רק לאחר אישור WhatsApp שלו/ה.

## פרטיות ושיווק
- נוסף עמוד `/unsubscribe.html` להסרה מדיוור שיווקי.
- נוסף API `POST /api/marketing/consent` לעדכון הסכמה/הסרה מדיוור לפי מייל.
- מדיניות הפרטיות עודכנה עם:
  - מפעיל השירות: מטיב שלמה הדר
  - שימוש בספקים WhatsApp/Meta, Firebase/Google, Render וכו׳
  - פרקי שמירת מידע
  - טיפול באירוע אבטחת מידע
  - הסרה מדיוור שיווקי
- תנאי השימוש עודכנו עם:
  - מפעיל השירות
  - הסרה מדיוור
  - הגבלת אחריות
  - הבהרה שהשירות אינו מוקד חירום/רפואי/ניטור
- דף מחיקת מידע עודכן עם יעד טיפול של עד 30 ימים ושמירת מידע מינימלי לפי צורך חוקי/אבטחתי.
- דף פידבק מזהיר לא לשלוח מידע רפואי או מידע רגיש.

## ניסוח ציבורי
- דף הבית רוכך משפטית:
  - במקום “מוודאת שההורה בסדר” → “בדיקת קשר יומית פשוטה ב־WhatsApp”.
  - חידוד: השירות מתאים רק כשלא נדרש ניטור רפואי או מענה חירום.

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.
- Smoke מקומי עם `MALACHI_ADMIN_TOKEN` עבר:
  - אדמין ו־API ניהוליים מחזירים 401 בלי token.
  - אדמין ו־dashboard מחזירים 200 עם token.
  - public POST feedback עובד.
  - public unsubscribe/marketing consent עובד.
  - API לא קיים מחזיר 404.
  - PNG asset מחזיר Content-Type תקין.

## הערת פריסה
ב־Render חובה להגדיר `MALACHI_ADMIN_TOKEN` כ־Environment Variable סודי. אם לא יוגדר, דפי האדמין יהיו נעולים עם 503 — בכוונה, כדי לא להשאיר מידע רגיש פתוח.
