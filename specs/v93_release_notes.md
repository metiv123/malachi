# מלאכי V93 - אזור אישי עם מייל וסיסמה

## מה נוסף
- נוסף דף כניסה חדש: `/login.html`.
- משתמשים יכולים להיכנס לאזור האישי עם מייל וסיסמה.
- בהרשמה אפשר להגדיר מייל וסיסמה כבר מהטופס.
- קישור הניהול הפרטי נשאר כגיבוי ולא נשבר.
- הדשבורד עודכן מ”דשבורד משפחתי” ל”אזור אישי למשפחה”.
- בתוך האזור האישי נוסף כרטיס “חשבון וכניסה”:
  - עדכון מייל כניסה
  - הגדרת/החלפת סיסמה
  - יציאה מהמכשיר
- לאחר login נשמר token מקומי בדפדפן כדי לפתוח את הדשבורד.

## אבטחה
- סיסמאות נשמרות כ־PBKDF2 SHA-256 עם salt ו־120,000 rounds.
- לא נשמרת סיסמה גלויה.
- אם משתמש לא מגדיר סיסמה, אפשר עדיין להיכנס דרך קישור הניהול הפרטי.

## בדיקות
- selftest הורחב לבדוק הרשמה עם מייל/סיסמה, login, והחלפת סיסמה.
- `npm test` עבר.
- `npm run test:consistency` עבר.
