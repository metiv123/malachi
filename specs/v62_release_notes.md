# מלאכי V62 - Release Notes

## שינוי
- שופר שיוך webhook לפי מספר WhatsApp כאשר קיימות כמה רשומות בדיקה עם אותו מספר.
- במקום לבחור את הקשיש הראשון עם מספר תואם, המערכת מעדיפה קשיש שיש לו צ׳ק פתוח (`sent`) האחרון בזמן.
- נוסף selftest שמייצר שתי משפחות עם אותו מספר, שולח צ׳ק פתוח לאחרונה, ומוודא שלחיצת מצוקה משויכת לצ׳ק הנכון.

## למה זה חשוב
- בבדיקות חיות השתמשנו באותו מספר לכמה משפחות דמו, וה-webhook שויך לרשומה ישנה ללא צ׳ק פתוח.
- התוצאה הייתה `Open check not found`, למרות שהכפתור הגיע.
- התיקון הופך בדיקות חוזרות עם אותו מספר לאמינות יותר.
