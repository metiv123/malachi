# מלאכי V73 - Release Notes

## כיוון MVP חדש
- נוסף מסמך עבודה `specs/v73_one_button_mvp_plan.md` שמגדיר את גרסת החינם הראשונה סביב כפתור אחד: “אני בסדר”.
- ההחלטה: לחיצה על “אני בסדר” מסמנת OK בדשבורד ולא שולחת הודעה למשפחה; התראה למשפחה נשלחת רק במקרה no-response.
- ד״ש למשפחה/עדכון יומי למשפחה נשמרים לפיצ׳רים עתידיים/פרימיום כדי לא לייקר את השימוש החינמי.

## שינויי קוד
- נוסף config פנימי `MALACHI_DAILY_CHECK_MODE` עם ברירת מחדל `legacy_two_button` כדי לא לשבור את baseline הקיים.
- במצב `single_ok`, `sendDailyCheck` שולחת הודעה עם כפתור אחד בלבד: `daily_ok` / “אני בסדר”.
- הודעות outbound של daily_check שומרות את mode במטא־דאטה לצורכי בדיקה ודיבוג.
- מיפוי webhook עודכן כך שגם הכפתור/טקסט “אני בסדר” מזוהים כ־OK.

## בדיקות
- selftest עודכן לבדוק מצב `single_ok`:
  - נשלח daily_check עם כפתור אחד בלבד.
  - כפתור “אני בסדר” מסמן את הבדיקה כ־OK.
  - OK לא יוצר הודעת משפחה (`family_greeting`, `distress_alert`, `no_response_alert`).
- `npm test` עבר בהצלחה.

## חשוב לפני Live
- אין לשנות את הסביבה החיה ל־`single_ok` עד שיש תבנית Meta מאושרת עם כפתור אחד.
- הגשת התבנית `daily_one_button_check_he` ל-Meta דורשת אישור משתמש מפורש כי זו פעולה חיצונית.
