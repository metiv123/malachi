# מלאכי V63 - Release Notes

## תיקון חיוני לשרת החי
- תוקן `sendOkAck`: במצב `WHATSAPP_PROVIDER=meta` הודעת האישור אחרי לחיצה על “הכול בסדר” נשלחת עכשיו בפועל כ־WhatsApp text message דרך Meta Cloud API, ולא רק נשמרת ביומן outbound.

## למה זה חשוב
- בבדיקת live V62, הלחיצה נקלטה והסטטוס עודכן ל־`ok`, אבל המשתמש לא קיבל הודעת אישור בפועל כי הקוד רק רשם `ok_ack` במסד הנתונים.
- עכשיו האישור אמור להישלח בפועל למספר של הלקוח בתוך חלון השיחה שנפתח אחרי האינטראקציה.

## לא נכלל בגרסה זו
- שינוי הכפתור “מצוקה” ל-“שלח ד״ש למשפחה” נשאר מוכן בנפרד, אבל לא נפרס ל-live עד שתבנית Meta החדשה תאושר, כדי לא ליצור בלבול בכפתורים.
