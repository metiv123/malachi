# מלאכי V126 — תגובת אימוג׳י ל“אני בסדר”

תאריך: 2026-07-25

## מה השתנה

- כאשר מבוגר לוחץ על “אני בסדר” דרך WhatsApp webhook, מלאכי שולח reaction emoji על ההודעה/הלחיצה עצמה במקום לשלוח הודעת תודה נפרדת בשגרה.
- ה־reaction ברירת מחדל: `❤️`.
- אם אין `messageId` נכנס, למשל בקריאה ידנית/מוקית פנימית, המערכת נשארת תואמת לאחור ושולחת `ok_ack` רגיל.
- נוספה פונקציית Meta Cloud API לשליחת `reaction` message.
- לוג outbound חדש: `ok_reaction`, כולל `inboundMessageId`, `checkId`, ו־`emoji`.

## למה

- פחות הודעות נפרדות למבוגר.
- חוויה טבעית ועדינה יותר: “ראינו אותך” בלי להציף את הצ׳אט.

## בדיקות

- `npm test` עבר בהצלחה.
- נוספו בדיקות שמוודאות ש־webhook של “אני בסדר” יוצר `ok_reaction` עם ה־messageId של ההודעה הנכנסת.
