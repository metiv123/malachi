# מלאכי V101 - ניהול פידבקים ברור

## שינוי
- נוסף דף ניהול ייעודי: `/admin-feedback.html`.
- הדף מציג פידבקים בכרטיסים ברורים במקום JSON גולמי:
  - דירוג
  - תאריך
  - טקסט הפידבק
  - משתמש/משפחה משויכים אם הפידבק נשלח מתוך האזור האישי
  - מקור ו־ID
- נוסף סיכום עליון: מספר פידבקים ודירוג ממוצע.
- דף האדמין קיבל קישור “ניהול פידבקים”, והכפתור הישן נשאר כ־raw לצורך debug.
- דף הפידבק `/feedback.html` שולח token אוטומטית אם הוא נפתח מתוך האזור האישי או אם יש token ב־localStorage.
- קישור “שליחת פידבק” באזור האישי מעביר token מפורש.
- שמירת הפידבק כוללת עכשיו הקשר משפחתי בטוח: familyId, שם מנהל, מייל וטלפון.
- נוספה תשתית אופציונלית להתראות webhook דרך `MALACHI_FEEDBACK_NOTIFY_WEBHOOK`. אם לא מוגדר — אין שליחה החוצה.

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.
- `node --check app/src/feedback.js` עבר.

## הערה
התראות לטלגרם/מייל בפועל עדיין דורשות יעד חיצוני/ספק שליחה. כרגע הדף הניהולי הוא המקום הברור לקבלת הפידבקים.
