# מלאכי V83 - Release Notes

## שינוי
- נוספה הפרדה ראשונה בין אתר ציבורי סטטי לבין API דינמי.
- נוספה בניית `static-site` מתוך `app/public` עם קישורים יחסיים שמתאימים ל־GitHub Pages / hosting סטטי.
- האתר הסטטי מגדיר `window.MALACHI_API_BASE = 'https://malachi-v78v.onrender.com'`, כך שהדפים עצמם נטענים סטטית והטופס/דשבורד מדברים עם ה־API רק כשצריך.
- נוסף CORS בסיסי ל־API כדי לאפשר לאתר סטטי בדומיין אחר לבצע קריאות הרשמה ודשבורד.
- נוספה GitHub Actions workflow לפריסת האתר הסטטי ל־GitHub Pages.

## למה זה נדרש
- Render מפיל/מחזיר 502/503 לכל השירות בגלים. דפי Privacy/Terms לא צריכים להיות תלויים בזמינות שרת Node.
- ההפרדה מאפשרת לדפי דף הבית/פרטיות/תנאי שימוש/מחיקת מידע להישאר זמינים גם כשה־API רגע לא זמין.
