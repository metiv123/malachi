# מלאכי V117 - מעטפת טעינה ושגיאה לדשבורד המשפחתי

## מה תוקן

- שינוי רק באזור הדשבורד המשפחתי.
- נוסף תוכן טעינה בתוך `#familyBox`, כדי שלא יופיע אזור ריק אם JavaScript נטען לאט או נתקע.
- `dashboard.js` נטען עם `defer` ופרמטר גרסה כדי לצמצם בעיות cache.
- נוספה הודעת שגיאה ברורה עם כפתור רענון אם טעינת הדשבורד נכשלת.
- שופרה כותרת/פתיח הדשבורד והריווח במובייל.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
