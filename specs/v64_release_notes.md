# מלאכי V64 - Release Notes

## תיקון זמן ישראל
- תוקן חישוב השעה בהודעות התראה שנשלחות דרך WhatsApp/Meta.
- במקום להשתמש באזור הזמן של השרת ב-Render (UTC), השעה מחושבת לפי `MALACHI_TIMEZONE`, וברירת המחדל היא `Asia/Jerusalem`.

## למה זה חשוב
- בבדיקת אי-מענה חיה הופיע פער של כ-3 שעות מהזמן בישראל.
- לאחר התיקון, זמן ההתראה אמור להופיע לפי שעון ישראל.
