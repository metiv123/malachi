# מלאכי V112 - הוספת בני משפחה/מבוגרים והגדרות אי־מענה

## מה השתנה

- כפתורי ההוספה באזור האישי הפכו לגלויים וברורים יותר:
  - `+ הוסף/י מבוגר`
  - `+ הוספת בן/בת משפחה נוסף להתראות`
- שופר סידור טופס הוספת/עריכת מבוגר:
  - שם המבוגר
  - טלפון המבוגר
  - שעת בדיקה יומית
  - שם איש קשר משפחתי
  - טלפון איש קשר
  - הגדרות אי־מענה
- כיתוב אישור ההצטרפות מיושר וצמוד יותר ל־checkbox כדי למנוע בלבול.
- נוספה הגדרה לכל מבוגר: אחרי כמה זמן לשלוח התראת אי־מענה:
  - 15 דקות
  - 30 דקות
  - 60 דקות
- נוספה הגדרה לכל מבוגר: כמה פעמים לשלוח התראת אי־מענה:
  - פעם אחת
  - פעמיים
  - שלוש פעמים
- מנגנון אי־המענה תומך כעת בהתראות חוזרות לפי ההגדרה של אותו מבוגר, במקום התראה אחת בלבד.

## ברירות מחדל

- התראה ראשונה אחרי 30 דקות.
- עד 2 התראות אי־מענה.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.

## הערת UX

לא נוספו שיפורי “שלחו לנו WhatsApp ראשון” או הודעות ביניים נוספות — בהתאם להנחיית המשתמש להמתין עם שיפורים 2 ו־3.
