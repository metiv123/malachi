# מלאכי V94 - צור משתמש / כניסת משתמש

## שינוי
- עודכנה שפת הממשק כך שיהיו שני מסלולים ברורים:
  - צור משתמש
  - כניסת משתמש
- דף הבית מציג כפתורים ברורים ליצירת משתמש ולכניסה.
- טופס ההרשמה נקרא עכשיו “צור משתמש” ומייצר משתמש + אזור אישי משפחתי.
- דף `/login.html` נקרא עכשיו “כניסת משתמש”.
- הודעת ההצלחה אחרי הרשמה עודכנה ל־“המשתמש והאזור האישי נוצרו בהצלחה”.

## למה
המשתמש ביקש שיהיה ברור במוצר שיש “צור משתמש” ו“כניסת משתמש”, במקום שהכול ייראה כמו קישור ניהול בלבד.

## הערה
זה עדיין משתמש באותו מודל קיים: משתמש משפחתי אחד שמחזיק אזור אישי לניהול המשפחה. קישור הניהול נשאר כגיבוי.
