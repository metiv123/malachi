# מלאכי V111 - תקשורת ברורה, שיוך Opt-in וניהול פשוט

## מה השתנה

- לאחר הרשמה באתר מוצג מסך הצלחה ברור שמסביר שהפרטים נשמרו, ושהודעות WhatsApp האוטומטיות ממתינות לאישור Meta. זה לא דורש Template כי ההודעה מוצגת באתר עצמו.
- שופר שיוך תגובות Opt-in נכנסות: אם אדם לחץ “מאשר/ת” ולא נמצא כקשיש או איש קשר ישיר, המערכת מנסה לשייך לפי מספר בעל החשבון ולאשר את אנשי הקשר שלו.
- נוסף endpoint פנימי לאדמין: `GET /api/admin/simple-overview`.
- נוסף כפתור “תמונת מצב פשוטה” בדף `admin.html`, שמציג בעברית פשוטה:
  - מי נרשם
  - מי ממתין לאישור
  - הודעות נכנסות אחרונות
  - הודעות שנשלחו / נכשלו
  - תכנית תבניות WhatsApp מצומצמת וברורה
- צומצמה אסטרטגיית התבניות העתידית לשלוש תבניות חובה:
  - `contact_optin_he` — אישור הצטרפות / איש קשר
  - `daily_check_he` — בדיקת בוקר
  - `no_response_alert_he` — התראה למשפחה כשאין מענה
- תבניות ד״ש/עדכון משפחתי/נוסח חלופי מסומנות כאופציונליות ולא כתלויות להפעלת הבטא.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
