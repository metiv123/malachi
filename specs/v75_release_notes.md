# מלאכי V75 - Release Notes

## הקשחת בטא
- נוסף דוח הקשחת בטא מלא: `specs/v75_beta_hardening_report.md`.
- הדוח כולל דוח ריג׳קטים ודוח תיקון, כולל חסמים חיצוניים כמו Meta token שפג תוקף ותבנית one-button שעדיין לא אושרה.

## נגישות
- נוסף רכיב נגישות לכל דפי האתר (`app/public/accessibility.js`).
- הרכיב כולל:
  - הגדלת טקסט.
  - ניגודיות גבוהה.
  - הדגשת קישורים.
  - איפוס העדפות.
- ההעדפות נשמרות בדפדפן בלבד.
- הרכיב הוזרק לכל דפי HTML הציבוריים.
- עודכנו סגנונות ב-`style.css`.

## משפטי / פרטיות / מחיקת מידע
- עודכנו:
  - `privacy.html`
  - `terms.html`
  - `data-deletion.html`
  - `faq.html`
  - `onboarding.html`
- הנוסחים מבהירים שמלאכי אינו מוקד חירום, אינו שירות רפואי, אינו ניטור רפואי ואינו מחליף קשר אנושי/טיפול/מוקדי חירום.
- הובהר שהשירות מופעל רק אחרי אישור האדם שמקבל את הודעות WhatsApp.
- דף מחיקת מידע חוזק עם מחיקה דרך הדשבורד או דרך אימייל.

## דשבורד משפחתי
- הוסר מה-UI כפתור “אשר Opt-in” כדי שמשפחה לא תאשר בשם ההורה.
- סטטוס opt-in מוצג בעברית: “ממתין לאישור ההורה”, “מאושר”, “בוטל/הוסר”.
- הוסר כפתור “דמה מצוקה” מה-UI של הבטא.
- סטטוס distress נשאר כתמיכה legacy בלבד.

## מסמכי עבודה
- עודכנו `specs/bot_messages_v1.md` ו-`specs/beta_operations_playbook.md` לכיוון כפתור אחד “אני בסדר”.
- הוסרה מהמסמכים הפעילים הצגת “מצוקה” כזרימת החינם הראשית.

## בדיקות
- וידוא שכל דפי HTML כוללים את `accessibility.js` בדיוק פעם אחת.
- `npm test` עבר בהצלחה.
- `npm run test:consistency` עבר בהצלחה.

- לא בוצע פרסום בפייסבוק.
- לא בוצע שינוי Live.
- לא נשלחו הודעות WhatsApp אמיתיות.
