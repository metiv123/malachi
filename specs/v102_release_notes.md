# מלאכי V102 - סידור האזור האישי

## שינוי
- האזור האישי עבר ממבנה ארוך ומבולגן למבנה כרטיסים מסודר.
- נוסף כרטיס עליון עם שם המשתמש, מייל ופעולות מהירות.
- כרטיס החשבון הופרד מהמשפחה וכולל עדכון מייל/סיסמה ופעולות מתקדמות.
- לכל הורה יש כרטיס ייעודי עם:
  - טלפון
  - שעה יומית
  - אישור WhatsApp
  - מצב אחרון
  - אנשי קשר
  - עריכה
  - היסטוריה ולוגים במצב מקופל
- פעולות מסוכנות/מתקדמות הועברו לאזור מקופל כדי שלא יבלבלו.
- כפתורים הוקטנו והותאמו לפרופורציה, במיוחד במובייל.
- אם אין עדיין הורה, טופס “הוספת פרטי משפחה” מוצג כשלב ברור בתוך האזור האישי.

## למה
המשתמש העיר שהבעיה אינה במסך יצירת משתמש אלא באזור האישי שנשאר לא מסודר וחסר פרופורציה.

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.
- `node --check app/public/dashboard.js` עבר.
