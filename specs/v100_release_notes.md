# מלאכי V100 - עיצוב אפליקציה למסכי משתמש

## שינוי
- דפי `/create-user.html` ו־`/login.html` עברו לעיצוב מובייל־פירסט נקי יותר.
- Header הופשט: לוגו + פעולה אחת בלבד.
- הטופס יושב בתוך כרטיס אפליקציה אחד, עם פחות עומס חזותי.
- אזור הקשר בתחתית הוקטן ל־“צריך עזרה?” עם שלושה אייקונים קומפקטיים.
- קישורי פרטיות/תנאים/דף הבית הוקטנו והועברו מתחת לאייקונים.
- הטקסטים קוצרו כדי שהמסך ירגיש פחות עמוס.

## למה
המשתמש שלח צילום מסך ואמר שהמסך עדיין לא נראה טוב. הבעיה הייתה עומס ניווט/פוטר וטופס שנראה כמו עמוד אתר ולא כמו מסך יצירת משתמש נקי.

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.
