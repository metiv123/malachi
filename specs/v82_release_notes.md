# מלאכי V82 - Release Notes

## שינוי
- נוסף GitHub Actions keepalive שמריץ ping ל־`/api/health` כל 5 דקות עם 3 ניסיונות.
- המטרה היא לצמצם 502/503 שנגרמים מ־Render free sleep או זמני התעוררות, במיוחד בלחיצה ראשונה על קישור סטטי כמו Privacy/Terms.

## למה זה נדרש
- התברר שהבעיה אינה `privacy.html` ספציפית: בזמן בדיקה גם `/terms.html` וגם `/api/health` החזירו זמנית 502/503.
- לאחר כחצי דקה השירות חזר ל־200 בכל הנתיבים. כלומר מדובר באי־זמינות זמנית של Render, לא href שגוי.

## מגבלה
- keepalive מצמצם את הסיכון, אך Render free עדיין לא מבטיח זמינות כמו שירות בתשלום.
