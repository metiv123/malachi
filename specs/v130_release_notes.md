# מלאכי V130 — מדידת כניסות והמרות בישראל ובבריטניה

תאריך: 2026-08-02

## מה נוסף

- מדידת צפיות ומבקרים משוערים בנפרד לאתר הישראלי ולאתר Angelo בבריטניה.
- מדידת לחיצות על הצטרפות, דמו, כניסת משתמש ו־WhatsApp.
- משפך הרשמה: התחלת הרשמה, השלמת הרשמה והצטרפות לרשימת המתנה.
- דוח מנהל ל־30 הימים האחרונים עם מקורות, קמפיינים ואחוז המרה.
- שמירת UTM במעבר בין דפי האתר ללא עוגיית פרסום.

## פרטיות

- כתובות IP גולמיות אינן נשמרות.
- מבקרים ייחודיים מחושבים כאומדן מצטבר באמצעות מבנה סטטיסטי, ללא רשימת מזהים אישיים.
- בוטים מזוהים ודפדפנים עם Do Not Track או Global Privacy Control אינם נספרים ככל האפשר.
- אין Meta Pixel או כלי פרסום חיצוני.
- נתוני המדידה המצטברים נשמרים עד 90 יום.
