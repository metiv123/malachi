# מלאכי V105 - נעילת דמות מותג רובוט עם כנפיים

## שינוי
- נבחרה דמות המותג: רובוט ידידותי עם כנפיים.
- הדמות הועברה לנכס ציבורי באתר: `/assets/brand/malachi-mascot.png`.
- הדמות מופיעה בדף הבית באזור ה־hero לצד דוגמת הודעת WhatsApp.
- הלוגו הטקסטואלי הקטן בראש האתר הוחלף בתמונת הדמות.
- נוספו favicon ו־apple-touch-icon לדפי האתר המרכזיים.
- נוסף שימוש עדין בדמות גם באזור footer של דף הבית.
- תמונת הפרופיל של WhatsApp Business עודכנה לאותה דמות רובוט עם כנפיים.

## למה
המשתמש אהב את כיוון הרובוט הידידותי עם הכנפיים ואישר לנעול אותו ככיוון מותג.

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.
- Meta WhatsApp Business Profile API אישר שיש תמונת פרופיל לאחר העדכון.
