# מלאכי V118 - מניעת כפילות אנשי קשר

## מה תוקן

- מניעת הוספת אותו מספר WhatsApp פעמיים לאותו מבוגר בצד שרת.
- נעילת כפתורי שמירה/הוספה בדשבורד בזמן פעולה כדי למנוע לחיצות כפולות.
- הודעת שגיאה ברורה כאשר איש קשר כבר קיים.
- נוספה בדיקת selftest שמוודאת שכפילות נדחית.
- נוקו בלייב 6 רשומות כפולות של אותו איש קשר, ונשארה רשומה אחת.

## הערה

- לא ניתן למחוק הודעות WhatsApp שכבר נשלחו לנמען דרך Meta Cloud API; אפשר רק למנוע שליחות כפולות בעתיד ולנקות רשומות במערכת.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
