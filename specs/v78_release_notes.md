# מלאכי V78 - Release Notes

## יציבות טעינת דפים אחרי 502 זמני
- נוסף `Cache-Control: no-store, max-age=0` לקבצים ציבוריים כדי לצמצם מצב שבו דפדפן/טלגרם ממשיכים להציג עמוד 502 ישן אחרי שהשרת כבר התאושש.
- נוסף header `X-Malachi-Version` לתשובות סטטיות כדי שאפשר יהיה לוודא בקלות איזו גרסה נטענת.

## בדיקות
- `npm test` עבר בהצלחה.
- `npm run test:consistency` עבר בהצלחה.

## לא בוצע
- לא שונה Live WhatsApp.
- לא שונתה תבנית Meta.
