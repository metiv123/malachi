# מלאכי V113 - תיקון טפסי הוספת מבוגר ובן משפחה

## מה תוקן

- כאשר אין עדיין מבוגר באזור האישי, טופס הוספת המבוגר מוצג פתוח וגלוי — בלי כפתור שמסתיר/סוגר אותו.
- כפתור הוספת מבוגר קיים רק כאשר כבר יש מבוגר אחד לפחות, ואז הוא פותח טופס נוסף.
- הוספת בן/בת משפחה נוסף הועברה לתוך אזור בני המשפחה בכרטיס המבוגר, עם כותרת גלויה וברורה.
- נוסף עיצוב קטן שמבדיל את אזור ההוספה מרשימת אנשי הקשר.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
