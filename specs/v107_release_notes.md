# מלאכי V107 - קישור גלוי להסרה מדיוור

## שינוי
- נוסף קישור גלוי ל־`/unsubscribe.html` בפוטר דף הבית תחת “הסרה מדיוור”.
- נוסף קישור “הסרה מדיוור” למסכי יצירת משתמש וכניסה, לצד פרטיות ותנאים.
- הקישור כבר היה קיים מתוך מדיניות הפרטיות ותנאי השימוש; V107 הופכת אותו לנגיש גם מהניווט הציבורי.

## למה
עמוד הסרה מדיוור אינו מספיק אם אין אליו קישור ברור באתר. זה חשוב גם לשקיפות, גם לאמון, וגם כהכנה לדיוור שיווקי עתידי.

## בדיקות
- נמצאו קישורי `/unsubscribe.html` בדף הבית, יצירת משתמש, כניסה, פרטיות ותנאים.
- `npm test` עבר.
- `npm run test:consistency` עבר.
