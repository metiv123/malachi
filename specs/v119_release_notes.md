# מלאכי V119 - תזכורות לפני התראת משפחה

## מה השתנה
- מנגנון אי־מענה עבר מהתראה מהירה למשפחה לזרימה רכה יותר:
  1. הודעת בדיקה ראשונה למבוגר.
  2. תזכורת למבוגר אחרי מרווח מוגדר.
  3. תזכורת נוספת לפי מספר הניסיונות.
  4. רק אחרי שכל הניסיונות הסתיימו ללא מענה — התראה למשפחה.
- ברירת מחדל חדשה: תזכורת כל 30 דקות, 3 ניסיונות למבוגר, התראה למשפחה אחרי כ־90 דקות.
- עד אישור תבנית Meta חדשה לתזכורת, התזכורות נשלחות עם תבנית הבדיקה היומית הקיימת (`daily_check_he`).
- דשבורד המשפחה עודכן כך שההגדרות מתארות תזכורות וניסיונות לפני התראת משפחה, לא מספר התראות למשפחה.
- נוספה תמיכה בקינפוג עתידי:
  - `MALACHI_REMINDER_INTERVAL_MINUTES`
  - `MALACHI_REMINDER_ATTEMPT_COUNT`
  - `META_TEMPLATE_DAILY_REMINDER`

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.

## הערת בטא
צריך לעדכן את המשפחות הקיימות לערכי ברירת המחדל החדשים: 30 דקות ו־3 ניסיונות, כדי שלא יישארו על הגדרות הבטא הישנות.
