# מלאכי V103 - תיקון פרופורציות אזור האישורים

## שינוי
- תוקן אזור האישורים במסך יצירת משתמש.
- ה־checkbox כבר לא מקבל גובה/פרופורציות של שדה טקסט.
- סודרו יישור, ריווח, גודל checkbox וגודל טקסט.
- קישורי תנאי שימוש/פרטיות מודגשים בצורה נקייה יותר.

## למה
המשתמש הצביע על אזור “קראתי ואני מאשר/ת” שנראה לא פרופורציונלי בגלל checkbox גדול ולא מיושר.

## בדיקות
- `npm test` עבר.
- `npm run test:consistency` עבר.
