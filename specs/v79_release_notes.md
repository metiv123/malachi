# מלאכי V79 - Release Notes

## הסרת קישורי עמודים נפרדים מתחתית דף הבית
- הוסרו מדף הבית קישורי “מדיניות מלאה”, “תנאי שימוש מלאים” ו“עמוד מחיקת מידע מלא” מתוך כרטיסי המידע התחתונים.
- כעת כל אזור התחתית בדף הבית נשאר בתוך אותו עמוד בלבד, כדי למנוע מצב שמשתמש לוחץ ומגיע ל־502 בדפדפן/טלגרם בזמן זמינות חלקית של Render.
- עמודי legal עדיין קיימים ישירות בשרת לצורכי Meta/בדיקה, אבל הם כבר לא מוצגים כקישורי תחתית בדף הבית.

## בדיקות

- `npm run test:consistency` עבר בהצלחה.
