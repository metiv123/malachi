# מלאכי V114 - טפסי הוספה גלויים ללא טאבים

## מה תוקן

- טופס הוספת מבוגר כבר לא נמצא בתוך תיבה נפתחת/טאב. הוא מוצג גלוי וברור.
- טופס הוספת בן/בת משפחה כבר לא מוסתר מאחורי שורת summary. הוא מוצג גלוי בתוך אזור בני המשפחה.
- הוסרה התנהגות שבה לחיצה על כותרת הייתה סוגרת את הטופס במקום לעזור למשתמש.

## בדיקות

- `npm test` עבר.
- `npm run test:consistency` עבר.
